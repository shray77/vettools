# VetTools — офлайн-инструмент ветврача «всё в одном»

Один самодостаточный HTML-файл. Без ИИ, без сервера, без интернета — работает с диска (file://), данные не покидают браузер (localStorage + экспорт/импорт JSON).

**Открыть онлайн:** https://shray77.github.io/vettools/

## Возможности (10 разделов)
1. **SOAP-приём** — структурированные заметки приёма
2. **Выписка владельцу** — + кнопка «копировать текст» для мессенджера
3. **Информированное согласие** — автогенерация документа из чек-боксов
4. **Лист наблюдения** — стационар, почасовые записи + **передача смены**: автодрафт для дежурного (шапка пациента, последний обход, «выполнено за сутки», динамика T/ЧСС/ЧД) с копированием и отдельной печатью
5. **Анестезиологический лист** — премедикация + мониторинг
6. **Протоколы** — 7 заготовок + свои шаблоны
7. **Некропсия** — патологоанатомическое вскрытие
8. **Клинический случай** — разбор с проверкой полноты по правилам (упомянуто УЗИ, но нет заключения; препарат без дозы; нет исхода — подсветит) + шкала готовности + черновик отчёта одним текстом
9. **6 калькуляторов** — доза (мг/кг→мл), инфузия и дефицит жидкости, RER/MER, BSA, конвертер единиц СИ↔условные, BCS/целевой вес
10. **Анализы «было → стало»** — динамика в % и статус относительно нормы

## Печать
Каждая вкладка печатается на A4 (Ctrl+P) — служебные панели скрываются автоматически.

## Резервные копии
Экспорт/импорт JSON-файла со всеми данными.

## Скачать
Файл [VetTools.html](VetTools.html) — сохранить на диск/телефон, открыть в любом браузере. Работает офлайн навсегда.
## Дисклеймер

VetTools — офлайн-инструмент «как есть», без гарантий полноты и точности. Справочники и калькуляторы дозировок носят ознакомительный характер и не являются назначением: дозу, препарат и схему подтверждайте по актуальной инструкции производителя и с ветеринарным врачом — даже если вы сами ветеринарный врач.
